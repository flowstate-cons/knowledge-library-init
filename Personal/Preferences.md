# Preferences

**Function:** record the owner's personal choices in how work is done and written, along with decisions already settled. This record keeps agents aligned with the owner and keeps settled questions settled.

## Overview

This page holds preferences that are matters of taste rather than correctness, with a dated record of settled and declined proposals. A permanent decline is enforced without being re-raised, and a deferred item is owed a return rather than treated as settled.

## Register

- How the owner likes updates, short or detailed, goes here.
- When an agent should just act, and when it should check first, goes here.
- Anything that would annoy the owner in how an agent works with them goes here.
