# Library Maintenance Queue

**Function:** small library improvements set aside for later, so they can be handled together at the right time.

## Overview

A shared queue lets current work continue uninterrupted. It is not a record of work being done, since the Log already records completed changes. It is not for project-sized work, in-progress renames, or sources waiting to be synthesized either. Those belong to the project tracker, a dedicated tracking page, and Source History.

## Before Adding An Item

- It is a small library fix that is not being done right now, such as moving a page, tidying a section, fixing a link, or closing a loose end.
- It is not a decision, and not a correction to a fact. Those go through the correction path in the Operating Manual instead.
- It is not project-sized. If the What needs more than a couple of sentences or a plan, it goes to the project tracker instead.
- It holds no credential, private client data, or anything that would not otherwise be written into the library.
- Search this page for the same fix first, and add to the existing item if one is found.

## Who Adds

The library manager writes every item. Another agent that notices a fix hands the owner a ready-to-paste entry in the template below, so nothing is lost in the relay. The library manager adds it at the next opportunity, or during the weekly review.

## Entry Template

```
### {{A short imperative title}}
- Status: {{status}} · Added: {{YYYY-MM-DD}} · By: {{who raised it}}
- Where: {{a link to the page or folder}}
- What: {{one to two sentences}}
- Context: {{optional, one line}}
```

## Statuses

- **Not Started.** Captured, waiting.
- **In Progress.** Being worked now.
- **Blocked.** Cannot proceed. The reason and what would unblock it are required on the item.
- **Deferred.** Deliberately postponed. A revisit date is required.
- **Completed.** Done, with the completion date added. The Log records the change itself.
- **Abandoned.** No longer worth doing. The reason and date are required.

## Weekly Review

Walk every open item, doing it, keeping it, deferring it with a date, or abandoning it with a reason. Confirm each Where link still resolves and repoint any that do not. A Deferred item past its date returns to Not Started. Re-check whether each Blocked item's blocker has cleared. Merge duplicates found along the way. Move anything that has grown into a project to the project tracker.

## Monthly Rollover

Completed and Abandoned items closed more than two full months ago move verbatim to Records/Maintenance Archive/YYYY-MM.md. Open items stay, whatever their age.

## Limitations

- More than about 30 open items is a signal to triage harder during the weekly review, or that some of the work is really a project that belongs on the tracker instead.
