# Source History

**Function:** one line for every source the library has received, tracking how far each has progressed. Oldest first. Added to, never rewritten.

## Overview

Each line names a source, links straight to the filed raw file, and gives when it arrived, who submitted it, how it came in, its current status, and an optional short note. There is no separate capture page. This line, together with the frontmatter summary on the raw file itself where it can carry one, is how a source that was never synthesized still gets found.

## Statuses

- **Filed.** Moved into raw, not yet synthesized into the library pages it informs.
- **Synthesized.** Its content is reflected in the library pages it informs, which cite it under their own Sources section.
- **Parked.** Filed, but deliberately held rather than synthesized, for example while waiting on the owner's decision about how to use it.
