# Page Standard

**Function:** state how a page's purpose is written, how a new page is started, and how a hub page is shaped. Following one standard allows every page to be read and maintained the same way.

## Writing A Purpose

A purpose is one to three sentences. The first sentence starts with a verb and states what the page does, at a high level. The next sentence states the benefit the page provides, usually with the word "allows." A purpose names what the page is for, and never explains how the page works, what it contains or what it excludes. It carries no facts, no examples, no negations and no pointers to other pages. The test is the same one you would apply to any tool, the way a coffee machine makes coffee.

The purpose lives on the page as its Function line, directly under the title.

### The Four Checks

Run these when a page is created, and again whenever it gains a section, is renamed, or the weekly review flags it as adrift.

- **Question.** Can you phrase what a reader arrives needing? If not, the likely fix is to merge the page into a sibling or delete it.
- **Rejects.** Can you name something plausible this page's purpose would not serve? If not, the likely fix is to sharpen the purpose so it excludes something real.
- **Neighbor.** Could a sibling page claim the same purpose? If so, the likely fix is to merge the two pages or sharpen both purposes so they stop overlapping.
- **Consequence.** Would anyone act differently if this page no longer existed? If not, the likely fix is to archive the page or move its content to Records.

## Starting A Page

Match a new page to its blueprint by what it records, not where it happens to sit.

| The page records | Blueprint | Folder |
|---|---|---|
| A general topic, fact grouping or process with no closer match below | Page | Wherever it fits the folder table in the Operating Manual |
| A step by step procedure or SOP | Guide | The Business subfolder it serves |
| A dated choice and why it was made | Key Decision | Agentic Layer/Key Decisions |
| One agent | Agent | Agentic Layer/Agents |
| One skill | Skill | Agentic Layer/Skills |
| A binding rule agents must follow | Standard | Agentic Layer/Standards |
| An investigation not yet confirmed | Research | Agentic Layer/Research |

Pages in Loops, Patterns and Reference use the Page blueprint. When nothing above fits cleanly, ask the owner rather than inventing a new blueprint.

## Hub Pages

Every hub page carries Function, Overview, Contents and Connections, in that order. Contents lists every page in the hub's folder with one line each. Adding, moving, renaming or retiring a page updates its hub's Contents in the same commit. Connections lists only pages directly related to the hub, never pages that merely mention the subject.
