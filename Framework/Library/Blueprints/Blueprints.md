# Blueprints

**Function:** the page skeletons every new page starts from. Copy one, fill it in, and delete any section with nothing to say.

## Overview

Each blueprint carries the bones a page of its kind needs, so a new page meets the standard from its first draft rather than being reshaped later.

## Contents

- [[Page Blueprint]] fits any general page.
- [[Guide Blueprint]] fits a procedure or SOP.
- [[Key Decision Blueprint]] fits a dated decision record.
- [[Agent Blueprint]] fits one agent.
- [[Skill Blueprint]] fits one skill.
- [[Standard Blueprint]] fits a set of binding rules.
- [[Research Blueprint]] fits an investigation and its findings.

A filed raw source gets no page of its own. [[Source Blueprint]] names the frontmatter to add to the raw file itself instead, and is not a page blueprint.

## Connections

- [[Page Standard]] holds Starting A Page, matching a new page to the right blueprint, and the Writing A Purpose guidance every page follows.
