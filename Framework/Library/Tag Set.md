# Tag Set

**Function:** state the baseline tags every page can carry, and the rule for adding more. A shared, small vocabulary allows pages to be found by topic without a tag pile that stops meaning anything.

## Baseline Tags

Nine tags ship with this framework. Each one has to be able to gather five to ten pages worth finding together, and fewer tags are better than more.

- **skill.** Pages about agent skills.
- **library.** Pages about the library itself.
- **governance.** How rules are set, owned and enforced.
- **agent.** Pages about agents themselves.
- **schema.** Data and field structure.
- **memory.** Pages about agent memories.
- **platform.** Facts about the platform agents run on.
- **prompt.** System prompts and prompt work.
- **visual.** Visual design, brand look, diagrams and video.

There are no folder tags and no brand tags. A page's folder already says where it sits, and repeating that as a tag adds nothing.

## Tagging A Page

Give a page the tags that fit from the list above, or `tags: []` where none of them fit. A page does not need a tag to be found. It needs one only when a tag genuinely groups it with other pages someone would want to find together.

## Adding A Tag

This is the baseline set only. Add a tag to your own workspace once a real need shows up, meaning you have searched for the same fix or subject twice and no existing tag covers it. Keep the same bar, five to ten pages worth finding together, before adding one, so the set stays worth reading in full. The full count and any additional tags beyond this baseline are for the owner to confirm.
