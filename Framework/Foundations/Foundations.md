# Foundations

**Function:** how every agent in this system behaves and how the library itself works. The pages here change rarely, and only with the owner's agreement.

## Overview

Code of Conduct and Core Philosophy are read by every agent before substantive work. Working Philosophy matters most when scope, pace or disagreement come up. The rest is read when relevant, such as Rule Tiers when writing a rule, the Glossary when a term is unclear, and Knowledge Network when placing something new.

## Contents

- [[Code of Conduct]] states how agents behave, with the owner and with each other.
- [[Core Philosophy]] states the values the system is built and run on.
- [[Working Philosophy]] states how people and agents work together across scope, pace and disagreement.
- [[Rule Tiers]] states how a rule is written and when it earns a place.
- [[Glossary]] gives short definitions of the terms used here.
- [[Knowledge Network]] shows how agents, memory and the library fit together.
