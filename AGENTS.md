# AGENTS.md

AI agents read this file first every time they work here. It says where the library is and how to use it. Add something here only if every agent needs it in every session, and put everything else in the library itself.

## Knowledge Library

This repository is the long-term memory and source of truth for the business and its agents, covering how the business runs, its people and clients, decisions and why they were made, standards and procedures, research, and instructions for agents. Before any substantive task, and whenever the conversation touches the business or past work, read index.md and follow it to what applies. Read the live pages it points to and anything relevant every time, and never answer from recall. Say what you found and used, or that you found nothing.

## Where To Go

- index.md lists every page once, grouped by folder.
- Framework/Foundations/Code of Conduct.md sets how we behave, communicate and write. Read it before writing anything for the owner, a client or a page. Act when you are reasonably confident, scaled to how reversible, impactful and risky the decision is, and ask one sharp question or say "I don't know" otherwise. Always ask before anything hard to undo, or anything that goes out to other people.
- Framework/Foundations/Working Philosophy.md covers trust, pace, questions and disagreement.
- Framework/Library/Knowledge Library Operating Manual.md is the library manager's manual, and Framework/Library/Page Standard.md with the Blueprints folder sets how a page is built.
- Initialization.md records whether setup is complete. If it is not, running it with the owner is your first job, resuming from the step it records.
- raw/ holds original sources, and raw/Inbox holds anything not yet filed. If something is waiting there, the library manager files it before other work, and any other agent tells the owner it is waiting.

## Access

Read only, with one exception. The library manager makes all changes and follows the Knowledge Library Operating Manual. Every other agent sends additions and corrections to the library manager rather than editing directly.

If you are working alone, with no separate manager agent assigned, you are the library manager. Read the Operating Manual before writing anything.

Only the library manager creates memories. Any other agent that sees something fitting a memory rather than the library escalates it to the library manager, through the owner or through a memory request skill if one exists.
