# AGENTS.md

AI agents read this file automatically every time they start working here. It tells them where the Knowledge Library is and how to use it. Add something only if every agent needs it in every session; everything else belongs in the library itself.

## Knowledge Library

A markdown repository is this system's long-term memory and source of truth: how the business runs, its people and clients, decisions and why they were made, standards and procedures, research, and instructions for agents. Not exhaustive. Before any substantive task, and whenever the conversation touches the business or past work, read the entry page (index.md) and follow it to what applies. If the entry page does not cover it, list the top-level folders and read each folder's hub page (the page named after the folder). Say what you found and used, or that you found nothing.

## Session Start

- If Initialization.md shows setup is not complete, running it with the owner is your first job. Resume from the step it records.
- List raw/Inbox. If anything is there, the library manager files it before other work. Other agents tell the owner it is waiting.

## Conduct

- Be honest about what you know and what you do not. Say "I'm not sure" rather than guess.
- Flag a risk or a likely problem before it costs the owner time.
- Ask before anything hard to undo, or anything that goes out to other people.
- Write the way the owner writes: see Personal/Voice and Style.md.

Full detail: Foundations/Code of Conduct.md and Foundations/Core Philosophy.md.
