# Skills

**Function:** a plain-language catalogue of the skills agents can run: what each does, who uses it, and whether it is active.

## Overview

A skill is a reusable capability an agent carries: reading the library, sending an email, pulling a report. The skill itself lives in the agent platform. Each page here is a snapshot of it, so a person can see at a glance what the agents can do without opening the platform.

Snapshots, not mirrors. A skill page records the purpose, scope, status and who uses it. It never copies the skill's instructions or code, because a copy drifts out of date the moment the skill changes. When a skill changes in a way that matters to a reader, the library manager updates its page and adds a Change Log line.

## Scope

- One page per skill, from the Skill blueprint.
- Every page records the skill's status in its Specification table: active, paused, planned or retired. A retired skill keeps its page, marked retired, so the record of what the agents could once do is not lost.

## Limitations

- The skill's instructions, code and credentials stay in the agent platform. Never paste them here.
- Which agent does what belongs in Agents. A skill page lists who uses it and links there.
