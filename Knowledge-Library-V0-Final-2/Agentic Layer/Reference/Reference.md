# Reference

**Function:** settled facts to look up: how a tool or platform behaves, its limits and quirks, account details (never passwords), and how the system is set up.

## Overview

Reference answers "what is true about X?" It holds facts that are confirmed and stable, written so an agent can look one up mid-task without reading anything else: a tool's limits, which account is used for what, how a platform handles files.

## Scope

- One page per subject, from the Page blueprint.
- Facts that are confirmed. Each page names where a fact came from in its Sources.

## Limitations

- A fact still being investigated, or not yet confirmed, is Research until it is.
- A rule about what agents must do is a Standard.
- Passwords, keys and other credentials never go in the library.
