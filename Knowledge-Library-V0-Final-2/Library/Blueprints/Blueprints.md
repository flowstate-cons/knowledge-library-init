# Blueprints

**Function:** the page skeletons every new page starts from. Copy one, fill it in, and delete any section with nothing to say.

## Pages

- [[Page Blueprint]]: any general page.
- [[Source Blueprint]]: the capture page for a raw source, filed in Library/Sources.
- [[Guide Blueprint]]: a procedure or SOP.
- [[Decision Blueprint]]: a dated decision record.
- [[Agent Blueprint]]: one agent.
- [[Skill Blueprint]]: one skill.
- [[Standard Blueprint]]: a set of binding rules.
- [[Research Blueprint]]: an investigation and its findings.

## Limitations

- Pages in Loops, Patterns and Reference use the Page blueprint.
