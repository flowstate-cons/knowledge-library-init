# Sources

**Function:** one capture page for each original document filed in raw: what it is, where it came from, and what it says.

## Overview

The original stays in raw, untouched. Its capture page lives here, built from the Source blueprint, and links to the library pages it informs.

## Scope

- One capture page per raw source.
- A newer version of a source gets its own capture page; the old one stays, marked as replaced.

## Limitations

- The synthesized knowledge belongs in the pillar pages, not here. A capture page summarizes one source; it is not where a topic lives.
