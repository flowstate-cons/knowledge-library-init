# Foundations

**Function:** how every agent in this system behaves and how the library itself works. The pages here change rarely, and only with the owner's agreement.

## Overview

Code of Conduct and Core Philosophy are read by every agent before substantive work. The rest is read when relevant: Rule Tiers when writing a rule, the Glossary when a term is unclear, and the Operating Manual by the library manager only.

## Pages

- [[Code of Conduct]]: how agents behave, with the owner and with each other.
- [[Core Philosophy]]: the values the system is built and run on.
- [[Operating Principles]]: how decisions get made.
- [[Rule Tiers]]: how a rule is written and when it earns a place.
- [[Glossary]]: short definitions of the terms used here.
- [[Knowledge Library and Network]]: how agents, memory and the library fit together.
- [[Knowledge Library Operating Manual]]: the library manager's working manual.

## Limitations

- Business facts, processes and preferences do not belong here. They go in Business or Personal.
