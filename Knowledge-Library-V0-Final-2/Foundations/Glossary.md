# Glossary

**Function:** short definitions of the terms used in this library. Look terms up here; it is not meant to be read through.

## Library

- **Knowledge Library:** this markdown repository. The business's long-term memory and source of truth, read by every agent.
- **Markdown Repository:** the technical name for the library: a folder of plain text files, kept in version control.
- **Entry Page:** index.md, where every agent starts.
- **Hub Page:** the page named after its folder. Says what belongs in the folder and lists its pages.
- **Blueprint:** a page skeleton in Library/Blueprints. Every new page starts from one.
- **Frontmatter:** the short block of fields at the top of a page (type, status, updated).
- **Raw:** the folder of original source material. Never edited.
- **Inbox:** raw/Inbox, where anyone can drop a file for the library manager to file.
- **Source:** one original document in raw. Its capture page, in Library/Sources, describes it.
- **Ingest:** reading a source and writing what it teaches into the right pages.
- **Log:** Library/log.md, a dated line for every change to the library.
- **Ingest History:** Library/Ingest History.md, one entry per source filed, with the reasoning behind where it went.

## Agents

- **Agent:** an AI assistant working in this system.
- **Library Manager:** the one agent assigned to manage the library. The only agent that writes to it.
- **Memory:** a short instruction or fact an agent platform keeps loaded for an agent. Small and always on; the library holds the depth.
- **Skill:** a packaged, repeatable capability an agent can run.
- **AGENTS.md:** the file agents read automatically at the start of every session.

## Rules

- **Law:** a rule with no exceptions. See [[Rule Tiers]].
- **Principle:** an expected behavior that allows a departure with a stated reason. See [[Rule Tiers]].
- **Candidate:** a proposed principle, waiting to prove itself in real work. See [[Core Philosophy]].
- **Decision Record:** a dated page recording a choice, the options considered, and why.

## What Goes Where

- **Standard:** a rule agents must follow. If an agent can be in violation of it, it is a Standard. Lives in Agentic Layer/Standards.
- **Pattern:** a proven method an agent chooses to use. Skipping it is not a violation. Lives in Agentic Layer/Patterns.
- **Reference:** a settled fact to look up: how a tool behaves, a limit, how something is set up. Lives in Agentic Layer/Reference.
- **Research:** an investigation and its findings, not yet confirmed. Moves to a settled page once confirmed. Lives in Agentic Layer/Research.
- **Decision:** a dated record of a choice and why. Never edited later. Lives in Agentic Layer/Decisions.
- **Loop:** a recurring process, with its trigger and steps. Lives in Agentic Layer/Loops.
- **Guide:** step-by-step instructions for a business task. Lives in the Business folder it belongs to.
