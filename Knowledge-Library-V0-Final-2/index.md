# Index

**Function:** the entry page of the Knowledge Library. Start here, find the folder that fits the task, then read that folder's hub page.

## Overview

Every folder has a hub page named after it (for example `Business/Business.md`). The hub says what belongs in the folder and lists its pages. Read the hub, then the page you need. If nothing here fits, list the folders and read their hubs.

## Folders

| Folder | Holds |
|---|---|
| [[Foundations]] | How every agent in this system behaves: conduct, philosophy, rules about rules, and how the library works. |
| [[Business]] | The company: operations, sales and marketing, tools, website, brand, voice and content. |
| [[Personal]] | The owner: profile, working style, and personal voice. |
| [[Agentic Layer]] | The agents themselves: agents, skills, standards, decisions, loops, patterns, reference, research. |
| Library/ | The library's own machinery: the change log, the ingest history, the page blueprints, and a capture page for each raw source. |
| raw/ | Original material, never edited. New files go in raw/Inbox. |
