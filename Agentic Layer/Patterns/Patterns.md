# Patterns

**Function:** proven methods worth reusing. A Pattern is a good way to do something that an agent chooses to use, and nobody is in violation for skipping it.

## Overview

When an approach works well more than once (a way of writing an SOP, a way to split work between agents, a checklist that catches mistakes), it is written up here so the next agent starts from it instead of rediscovering it. Each page covers when to use it, how it works, why it works, and an example where it helps.

A Pattern that becomes so important that skipping it is a mistake gets promoted to a Standard, with the owner's agreement.
