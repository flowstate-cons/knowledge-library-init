# Reference

**Function:** settled facts to look up, such as how a tool or platform behaves, its limits and quirks, account details (never passwords), and how the system is set up.

## Overview

Reference answers "what is true about X." It holds facts that are confirmed and stable, written so an agent can look one up mid task without reading anything else, such as a tool's limits, which account is used for what, or how a platform handles files. Each page comes from the Page blueprint, and names where its fact came from in its own Sources.
