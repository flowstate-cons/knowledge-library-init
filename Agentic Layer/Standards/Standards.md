# Standards

**Function:** the binding rules for how work is done. The test is whether an agent can be in violation of it. If so, it is a Standard.

## Overview

A Standard is a rule the agents must follow, such as "every client email is reviewed by the owner before it is sent" or "prices are only quoted from the current price sheet." Each rule is marked as a Law (no exceptions) or a Principle (expected, departure allowed with a stated reason). See [[Rule Tiers]].

Standards are earned, not declared. A rule usually starts life as a Candidate in Core Philosophy or as a Pattern that keeps proving itself, and is promoted here with the owner's agreement once it has. Each page comes from the Standard blueprint, covers one area of work, and holds only rules the owner has agreed to.
