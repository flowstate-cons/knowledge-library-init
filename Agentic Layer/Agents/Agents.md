# Agents

**Function:** the roster of the agent team, one page per agent, saying what it is for, what it covers, and what it leaves to others.

## Overview

This folder maps the team of agents the business is building toward, not just the ones running today. The library manager's page is created at setup. Every agent added after that gets a page here first, before it starts work, so its job is written down and it does not overlap with an agent that already exists.

A typical team grows from the library manager toward agents for sales, operations, content and research. Each one reads the library, and only the library manager writes to it.

Each page comes from the Agent blueprint, covers purpose, scope, limitations, status (active, paused, planned or retired), and the skills it runs, and stays a snapshot of the agent's role. A planned agent can have a page, marked `planned` in its Specification table, before it is built. An agent page's full instructions (system prompt, settings) stay in the agent platform, since the page summarizes them and never copies them.
