# Agentic Layer Overview

**Function:** give every reader a way into the agent system. A single entry point allows anyone to find what an agent does without searching each subfolder.

## Overview

The agents working in this system, and everything about how they operate, live here. Each subfolder has a hub explaining what belongs in it. When none of the subfolders below fit, see What Goes Where in the [[Glossary]].

## Contents

- [[Agents]] holds one page per agent.
- [[Skills]] describes what each skill does.
- [[Standards]] holds the rules agents must follow. If an agent can be in violation of a rule, it belongs here.
- [[Patterns]] holds proven methods an agent chooses to use.
- [[Reference]] holds settled facts to look up.
- [[Research]] holds investigations and findings not yet confirmed.
- [[Key Decisions]] holds dated records of choices.
- [[Loops]] holds recurring processes.

## Connections

- [[Business Overview]] holds business processes, even when an agent runs them.
