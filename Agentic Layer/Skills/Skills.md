# Skills

**Function:** a plain-language catalog of the skills agents can run, covering what each does, who uses it, and whether it is active.

## Overview

A skill is a reusable capability an agent carries, such as reading the library, sending an email, or pulling a report. The skill itself lives in the agent platform. Each page here is a snapshot of it, so a person can see at a glance what the agents can do without opening the platform.

Snapshots, not mirrors. A skill page records the purpose, scope, status and who uses it, from the Skill blueprint. It never copies the skill's instructions or code, because a copy drifts out of date the moment the skill changes. When a skill changes in a way that matters to a reader, the library manager updates its page and adds a Change Log line. Every page records the skill's status in its Specification table, meaning active, paused, planned or retired. A retired skill keeps its page, marked retired, so the record of what the agents could once do is not lost. The skill's instructions, code and credentials stay in the agent platform, and are never pasted here.
